# Caching

The iRacing Data Client SDK supports opt-in caching via pluggable stores powered by `@http-client-toolkit/core`. When a `CacheStore` is provided, S3 responses are cached automatically with TTL derived from the presigned URL's expiry — no manual TTL management needed.

<Aside type="note">
  Caching is **not enabled by default**. Without a `stores.cache`, every API call makes a network request. This matches the behaviour of previous SDK versions.
</Aside>

## Enabling Caching

Pass a `CacheStore` implementation via the `stores` option:

```typescript
import { IRacingDataClient } from 'iracing-data-client';

const iracing = new IRacingDataClient({
  auth: { /* ... */ },
  stores: {
    cache: myCacheStore,
  },
});

// First call — network request, response is cached
const cars1 = await iracing.car.get();

// Second call within cache period — returned from store
const cars2 = await iracing.car.get();
```

### How It Works

When caching is enabled:

1. **S3 Link Resolution** — The SDK follows presigned S3 URLs returned by the iRacing API
2. **TTL Derivation** — Cache TTL is automatically calculated from the S3 link's `expires` field
3. **Cache Key** — Generated from the full request URL including query parameters
4. **Transparent** — Cached responses are returned automatically; no code changes needed per-call

### Cache Key Generation

Cache keys are derived from the request URL and parameters, so different parameters produce different cache entries:

```typescript
await iracing.member.get({ custIds: [123456] });  // Cache key 1
await iracing.member.get({ custIds: [789012] });  // Cache key 2
await iracing.member.get({ custIds: [123456] });  // Hits cache key 1
```

## Store Implementations

### Using a Package

Check the [`@http-client-toolkit`](https://github.com/http-client-toolkit) organisation for available store packages:

```typescript
import { IRacingDataClient } from 'iracing-data-client';
import { RedisCacheStore } from '@http-client-toolkit/store-redis'; // example

const iracing = new IRacingDataClient({
  auth: { /* ... */ },
  stores: {
    cache: new RedisCacheStore({ url: 'redis://localhost:6379' }),
  },
});
```

### Implementing Your Own

A `CacheStore` implements the following interface:

```typescript
interface CacheStore {
  get(key: string): Promise<Response | undefined> | Response | undefined;
  set(key: string, value: Response, ttl?: number): Promise<void> | void;
  delete(key: string): Promise<void> | void;
}
```

Simple in-memory example:

```typescript
class InMemoryCacheStore {
  private cache = new Map<string, { response: Response; expires: number }>();

  get(key: string): Response | undefined {
    const entry = this.cache.get(key);
    if (!entry) return undefined;
    if (entry.expires < Date.now()) {
      this.cache.delete(key);
      return undefined;
    }
    return entry.response.clone();
  }

  set(key: string, value: Response, ttl?: number): void {
    this.cache.set(key, {
      response: value.clone(),
      expires: Date.now() + (ttl ?? 300) * 1000,
    });
  }

  delete(key: string): void {
    this.cache.delete(key);
  }
}

const iracing = new IRacingDataClient({
  auth: { /* ... */ },
  stores: {
    cache: new InMemoryCacheStore(),
  },
});
```

## Application-Level Caching

If you need caching logic beyond what the store provides (e.g. custom TTLs per endpoint, conditional caching), you can layer your own cache on top:

```typescript
class CachedIRacingService {
  private cache = new Map<string, { data: unknown; expires: number }>();

  constructor(private iracing: IRacingDataClient) {}

  async getMemberInfo(
    custId: number,
    cacheDuration = 5 * 60 * 1000  // 5 minutes
  ) {
    const cacheKey = `member:${custId}`;
    const cached = this.cache.get(cacheKey);

    if (cached && cached.expires > Date.now()) {
      return cached.data;
    }

    const data = await this.iracing.member.get({ custIds: [custId] });

    this.cache.set(cacheKey, {
      data,
      expires: Date.now() + cacheDuration,
    });

    return data;
  }

  clearCache() {
    this.cache.clear();
  }
}
```

## Cache Optimization

### Preloading

Warm up the cache on application start:

```typescript
async function preloadCache(iracing: IRacingDataClient) {
  await Promise.all([
    iracing.car.get(),
    iracing.track.get(),
    iracing.series.get(),
    iracing.constants.categories(),
    iracing.constants.divisions(),
  ]);
}

await preloadCache(iracing);
```

### Batch Requests

Combine requests to reduce cache entries and API calls:

```typescript
// Instead of fetching members one at a time
const ids = [123, 456, 789];

// Single batched request
const members = await iracing.member.get({ custIds: ids });
```
