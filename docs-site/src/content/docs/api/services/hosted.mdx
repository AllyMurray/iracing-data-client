# Hosted Service

The Hosted service provides access to hosted (private) session data.

```typescript
const hostedService = iracing.hosted;
```

## Methods

### `combinedSessions(params?)`

Get combined hosted sessions, optionally filtered by package ID.

<Tabs>
  <TabItem label="Details">
    **Returns:** `Promise<HostedCombinedSessionsResponse>`

    **Parameters:**
    - `packageId?: number` - Filter by content package ID

    **Description:** Returns a combined list of hosted sessions. Optionally filter by a specific content package.
  </TabItem>
  <TabItem label="Example">
    ```typescript
    // Get all combined sessions
    const sessions = await iracing.hosted.combinedSessions();

    // Filter by package ID
    const filtered = await iracing.hosted.combinedSessions({
      packageId: 123
    });
    ```
  </TabItem>
</Tabs>

---

### `sessions()`

Get hosted sessions.

<Tabs>
  <TabItem label="Details">
    **Returns:** `Promise<HostedSessionsResponse>`

    **Parameters:** None

    **Description:** Returns a list of currently available hosted sessions.
  </TabItem>
  <TabItem label="Example">
    ```typescript
    const sessions = await iracing.hosted.sessions();

    sessions.forEach(session => {
      console.log(`Session: ${session.sessionName}`);
    });
    ```
  </TabItem>
</Tabs>

<Aside type="note">
  Hosted session data is dynamic and changes frequently. Avoid caching this data for extended periods.
</Aside>
