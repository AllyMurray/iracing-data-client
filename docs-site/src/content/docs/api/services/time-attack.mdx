# Time Attack Service

The Time Attack service provides access to time attack competition data.

```typescript
const timeAttackService = iracing.timeAttack;
```

## Methods

### `memberSeasonResults(params)`

Get a member's time attack season results.

<Tabs>
  <TabItem label="Details">
    **Returns:** `Promise<TimeAttackMemberSeasonResultsResponse>`

    **Parameters:**
    - `taCompSeasonId: number` **(required)** - The time attack competition season ID

    **Description:** Returns the authenticated member's results for a specific time attack competition season.
  </TabItem>
  <TabItem label="Example">
    ```typescript
    const results = await iracing.timeAttack.memberSeasonResults({
      taCompSeasonId: 456
    });

    console.log('Time Attack Results:', results);
    ```
  </TabItem>
</Tabs>
